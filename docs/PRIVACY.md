# 개인정보 처리방침 — 문서 뷰어

시행일: 2026-10-21

**문서 뷰어**(이하 "앱")는 사용자의 문서를 보는 앱입니다.

## 수집하는 정보
앱은 개인정보를 수집·저장·전송하지 않습니다.

- 사용자가 연 문서(PDF, Word, Excel, PowerPoint, 한글, 텍스트, 이미지)는 기기 안에서만 처리되며 외부 서버로 전송되지 않습니다.
- 문서 표시를 위해 앱 내부에서 기기 안(127.0.0.1)으로만 통신하는 임시 서버를 사용하며, 외부에서 접근할 수 없습니다.
- 최근 문서 목록, 읽던 위치, 책갈피, 글자 설정은 기기 안의 앱 저장소에만 보관되며 앱 삭제 시 함께 지워집니다.
- 암호가 걸린 문서의 비밀번호는 복호화에만 쓰이고 저장하지 않습니다.
- 광고, 분석, 추적 도구를 사용하지 않습니다.

## 권한
- **인터넷**: 기기 안에서 문서를 표시하는 데 필요합니다. 문서 안의 웹 링크를 눌렀을 때에만 사용자의 브라우저가 열립니다.
- **파일 접근**: 사용자가 직접 고른 문서, 또는 다른 앱에서 "연결 프로그램"으로 넘긴 문서만 읽습니다. 저장소 전체에 접근하지 않습니다.

## 제3자 제공
없습니다.
